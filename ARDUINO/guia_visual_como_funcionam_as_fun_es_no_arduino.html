O que é uma Função no Microcontrolador?

Uma função é um bloco de código autônomo que realiza uma tarefa específica. Ela recebe dados de entrada (parâmetros), executa instruções lógicas e pode (ou não) devolver um resultado (retorno).

Reutilização

Evita repetição de código no programa.

Organização

Divide problemas complexos em partes.

Manutenção

Facilita correções e depuração.

Modelo Mental de Entrada / Processamento / Saída

Entradas (Parâmetros) int v1, int v2
Processamento Interno
resultado = v1 + v2;
Executa o algoritmo isolado
Saída (Valor Retornado) return resultado;

2. Fluxo de Execução no Microcontrolador

A CPU do Arduino executa o código sequencialmente. Quando encontra uma função, o ponteiro de instrução salta para a função e depois retorna.

Passo Atual: 1 / 6
Fluxo Principal (CPU Main)
void setup() {
  pinMode(13, OUTPUT);
}
void loop() {
// Chamando a função customizada:
piscarAlerta(3, 200);
// Continua execução no loop...
delay(1000);
}
Sub-Rotina / Função Auxiliar Ponteiro da CPU
void piscarAlerta(int vezes, int ms) {
  for(int i = 0; i < vezes; i++) {
    digitalWrite(13, HIGH);
    delay(ms);
    digitalWrite(13, LOW);
    delay(ms);
  }
  // Fim da função: retorna ao loop()
}
O que a CPU está fazendo?

O programa inicia executando as configurações do setup() uma única vez após ser energizado.

3. Matriz dos 4 Tipos de Funções

Dependendo da necessidade do projeto, uma função pode ter ou não argumentos e retorno.

1. Sem Retorno / Sem Parâmetros void acenderLED()

Executa uma ação fixa no circuito sem precisar de dados externos nem responder nada.

void acenderAlerta() {
  digitalWrite(13, HIGH);
}
2. Sem Retorno / Com Parâmetros void ligarPino(int pino)

Recebe dados de configuração externos para personalizar a ação (ex: qual pino acionar).

void acionarRele(int pino, bool estado) {
  digitalWrite(pino, estado);
}
3. Com Retorno / Sem Parâmetros int lerBotoes()

Lê um sensor ou estado fixo do hardware e devolve a resposta para quem chamou.

int lerNivelTanque() {
  int valor = analogRead(A0);
  return valor;
}
4. Com Retorno / Com Parâmetros float converter(float v)

Realiza cálculos matemáticos ou conversões complexas com os dados informados.

float converterCelsius(float fahrenheit) {
  return (fahrenheit - 32) * 5.0 / 9.0;
}

4. Escopo de Variáveis (Global vs. Local)

Entenda onde suas variáveis existem na memória RAM durante a execução das funções.

Variável Global

Declarada fora de qualquer função (no topo do programa). Ela permanece ativa durante todo o tempo de execução e pode ser lida ou alterada por qualquer função.

int contadorGlobal = 0; // Global

void loop() {
  contadorGlobal++; // Acessível aqui!
}

Variável Local

Declarada dentro de uma função. Ela nasce quando a função é chamada e é destruída da memória assim que a função termina a execução.

void calcularTempo() {
  int inicioLocal = millis(); // Local
} // inicioLocal deixa de existir aqui!
